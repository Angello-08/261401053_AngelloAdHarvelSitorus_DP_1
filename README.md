## ▶️ Cara Menjalankan

1. Pastikan [Free Pascal](https://www.freepascal.org/) sudah terpasang.
2. Clone repositori ini:
```bash
   git clone https://github.com/<username>/<nama-repositori>.git
   cd <nama-repositori>
```
3. Kompilasi dan jalankan salah satu program, misalnya Soal 1:
```bash
   fpc Soal1_261401053_AngelloAdHarvelSitorus.pas
   ./Soal1_261401053_AngelloAdHarvelSitorus
```
   Di Windows, jalankan dengan `Soal1_261401053_AngelloAdHarvelSitorus.exe`.
